# 🤖 WhatsApp AI Auto-Responder
A Python-based automation tool that uses Computer Vision and LLMs to detect, process, and respond to WhatsApp messages in real-time.

# 📝 Project Summary
This script automates the process of reading and replying to messages. It uses PyAutoGUI to interact with the desktop interface, pyperclip for clipboard management, and the Groq API to generate human-like, context-aware responses in English, Hindi, and Bengali (Hinglish/Banglish).

# ✨ Key Features
Screen Scraping: Automatically moves the cursor and drags to capture chat history.
Smart Cleaning: Uses Regex to strip out timestamps and metadata for clean AI input.
Personality-Driven: Configured with a "fun and caring friend" persona for natural conversation.
Multilingual Support: Handles code-switching between English, Hindi, and Bengali.
